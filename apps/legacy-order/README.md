# 老品下单执行器（首版）

首版采用 **Playwright 直连团队成员自己的 Chrome**，不保存账号密码，不依赖 OpenClaw 浏览器扩展。

## Playwright 是什么？

Playwright 是微软开源的浏览器自动化库。它不是 AI，也不是录制鼠标的工具；它让程序直接读取网页元素、填写表单、等待页面状态、处理浏览器原生确认框并截图。

与当前扩展链路相比，它直接连接本机 Chrome：

```text
Excel → 执行器 → Playwright → 团队成员已登录的 Chrome → 采购系统
```

因此可稳定处理网页加载、跳转、新标签和 `confirm()` 弹窗，并把每步状态写入本地台账。

## 正式版能力

- 读取 Excel 的 `料号`、`下单数量`；
- 只读模式：精确查 SKU、筛选未处理、定位第一条；
- 保存网页截图和 JSON 执行台账；
- 回写 Excel 状态、异常说明、开始/结束时间；
- 遇到异常不会阻断下一行；
- 不保存密码、Cookie、SSO Ticket。

## 当前边界

默认仅 `dry-run`，不会生成 PN/PP、提交或审核。生产写入阶段必须在测试验证后按批次明确启用，并为每个写入动作增加“查询回读 + 幂等校验”。

## 每人安装与运行

1. 安装 Node.js LTS（建议 v20 或更高）。
2. 解压本文件夹到本机，例如桌面。
3. 打开 Chrome，使用自己的采购账号登录采购系统。
4. **关闭所有 Chrome 后**，从 Windows 命令提示符运行：

```cmd
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="%LOCALAPPDATA%\采购自动化Chrome"
```

首次启动后，在该 Chrome 中按公司正常方式登录采购系统。之后不要把个人密码写入脚本或配置。

5. 复制 `config.example.json` 为 `config.json`，填入自己的 Excel 路径。
6. 在本文件夹运行：

```cmd
npm install
npm run dry-run
```

输出位于 `runs/<时间>/`：

```text
run.json      每行状态台账
screenshots/  只读校验和异常证据
结果-原文件名.xlsx  自动回写的 Excel
```

## 团队部署原则

- 每个人用自己的采购系统账号；脚本不存密码。
- 先用 `dry-run` 验证每个账号的查询权限和页面结构。
- 执行器会固定：精确 SKU + 未处理 + 只取第一条。
- 生产动作由管理员发放带批次授权的配置；不要改脚本中的模式绕过审批。
- 页面改版后先跑只读校验，确认选择器仍正确。

## 正式执行方式

```text
1. 双击 启动专用采购Chrome.cmd
2. 用本人账号登录采购系统
3. 将仅包含已批准任务的 Excel 路径填入 config.json
4. 双击 运行完整下单.cmd
5. 输入 YES
6. 从 runs/<时间>/ 下载结果 Excel 与 run.json
```

完整链路已在生产环境验证：

```text
SPC000269_CLB｜100
DM202609160024175
PN2026091619423187969
PP2026091619423738264｜审核通过
```
