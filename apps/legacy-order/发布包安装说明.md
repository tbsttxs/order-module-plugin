# 团队安装说明（v4）

## 业务人员只需要做一次

1. 解压收到的 `老品下单工作台-团队发布包-v4.zip`。
2. 双击 `安装老品下单工作台.cmd`。
3. 安装程序会自动：
   - 复制工作台到当前 Windows 用户本地目录；
   - 在桌面创建“老品下单工作台”快捷方式；
   - 启动工作台网页和专用采购 Chrome。
4. 首次请在专用 Chrome 中登录采购系统。以后从桌面快捷方式打开即可。

## 每次使用

双击桌面“老品下单工作台” → 上传 Excel → 选择执行方式 → 开始。

无需安装 Node.js、无需输入命令、无需手动启动 Chrome/CDP 服务。

## 文件说明

| 文件/文件夹 | 是否需要手动操作 | 作用 |
|---|---:|---|
| `安装老品下单工作台.cmd` | 仅首次双击 | 安装并创建桌面快捷方式 |
| `一键启动工作台.cmd` | 安装后由桌面快捷方式调用 | 启动守护服务和网页 |
| `watchdog.mjs` | 否 | 服务异常时自动重启工作台 |
| `server.mjs` | 否 | 本机网页、上传、下载与任务管理 |
| `runner.mjs` | 否 | 执行采购网页自动化 |
| `runtime/` | 否 | 内置 Node 运行环境，无需自行安装 Node.js |
| `public/` | 否 | 工作台网页界面 |
| `runs/` | 自动生成 | 每次运行的台账、截图和回写 Excel |
| `uploads/` | 自动生成 | 上传 Excel 的本地临时副本 |

不要手动修改 `runner.mjs`、`server.mjs`、`runtime/` 或 `node_modules/`。
