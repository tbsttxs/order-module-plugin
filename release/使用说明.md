# 下单工作台 v0.1.0-pilot

## 启动

1. 解压整个文件夹，不要只复制其中一个文件。
2. 双击 `start-pilot.cmd`。
3. 等待浏览器打开 `http://127.0.0.1:8791/`。
4. 在工作台输入自己的采购账号和密码，按页面提示登录。

每位成员使用自己的 Windows 凭据和专用 Chrome 配置。请不要复制其他人的 Chrome Profile、Cookie、账号密码或运行结果。

## 使用边界

- 首次建议先做只读预检。
- 正式下单前确认料号、数量、登录账号和业务授权。
- 不要关闭工作台自动打开的专用 Chrome。
- 遇到异常不要重复点击正式下单；先保存反馈信息。

## 停止

双击 `stop-pilot.cmd`。停止不会删除本机凭据、Chrome 配置或结果文件。

## 反馈

请填写同目录的 `反馈模板.md`，并附上脱敏后的截图或结果文件。禁止发送密码、Cookie、SSO ticket 或完整账号信息。
