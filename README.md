# 下单模块（本地融合原型）

统一入口包含两个独立业务变体：

- **老品下单**：Hard采购需求 → 分仓 → PN/PP → 审核；
- **新品下单**：美西料号预警 → 采购订单 → 待审核编辑数量 → 保存回读。

## 当前架构

```text
下单模块入口（127.0.0.1:8791）
├─ apps/legacy-order/  老品下单，独立服务 127.0.0.1:8787
└─ apps/new-order/     新品下单，独立服务 127.0.0.1:8790
```

入口负责模块选择与本地服务启动；变体执行器、Excel、页面与结果规则保持隔离，防止误用老品规则处理新品。

## 凭据边界

当前各原型仍保有自己的兼容登录实现。正式接入采购工作台 Host 后，账号密码只由 Host 通过 Windows Credential Manager 管理；插件仅请求已授权的登录会话，绝不保存凭据、Cookie、SSO ticket 或浏览器 Profile。

## 试用限制

仅绑定本机 loopback。正式写入保留各变体自身确认门槛和回读要求。
